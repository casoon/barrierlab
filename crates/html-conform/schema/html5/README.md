# schema/html5

Vendored RELAX NG schema for HTML5 grammar / content-model validation,
derived from the Nu Html Checker (`validator/validator`, MIT-licensed).

Not hand-edited — updated only via the `xtask/vendor-*.sh` scripts; local
deviations are the patches in `xtask/schema-patches/`. See
`plan/03-schema-vendoring.md` and `plan/DECISIONS.md`.
