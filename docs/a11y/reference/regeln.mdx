`structure_metas`, `semantics_metas`, `rendering_metas` and `stylesheet_metas`;
`examples/a11y/rules.json` is their output. The severity is the rule's default; individual findings
may deviate from it. Each row has an anchor: the ID with `/` replaced by `-`
(`images/alt-missing` is `#images-alt-missing`). `a11y-static` sets it as `help_url` on its findings.

## review instead of fail

Not every missing item is a violation. `landmarks/navigation-missing`,
`landmarks/banner-missing`, `landmarks/contentinfo-missing`, `headings/h1-multiple` and
`keyboard/skip-link-missing` return `review`: `main` must be present, but a page may do without
navigation, and a skip link can only be recognized by its link text and class names.
`links/ambiguous-name` and `links/generic-name` are two different rules and both return
`review`: one says "two links have the same name but go to different places", the other "this text
says nothing about the destination on its own".
